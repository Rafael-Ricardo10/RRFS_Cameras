# 📹 RRFS Cameras

**RRFS Cameras** é um sistema de **monitoramento de câmeras IP**. Com ele você acompanha, grava e analisa as imagens das suas câmeras em um só lugar.

---

## ✨ Funcionalidades

- 👁️ **Monitoramento** de câmeras IP em tempo real
- 🎥 **Gravação** das imagens
- 🧍 **Detecção de pessoas**
- 📦 **Detecção de objetos**
- 🎛️ **Controle de câmeras PTZ**, para mover a câmera (esquerda, direita, cima, baixo e zoom)
- ...e outras funcionalidades

---
